IDEA solved "Wrong tab" Warning Message

Posted by 曉羽 on Wednesday, April 20, 2022

其實這個問題的根本就是：在 Java Doc 裡不存在這個標籤、所以只需在設定中新增標籤即可。

注意事項：需在 Default IDE 裡做設定、才不會下一次開新的 Project 時又出現錯誤。

配置路徑如下： Settings / Preferences -> Editor -> Inspections -> Java -> Javadoc -> Javadoc declaration problems -> Options -> Additional Javadoc tags
