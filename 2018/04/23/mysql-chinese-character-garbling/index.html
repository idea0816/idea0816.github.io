MAC 下 mysql 中文亂碼-找不到 my-default.cnf 和 my.cnf

Posted by 曉羽 on Monday, April 23, 2018

在 mac 下安裝好 mysql 後；以 MySQLWorkbench 進入 Server 並輸入以下命令：

show variables like 'character_set_%'

一般來說、 MySQL 預設是拉丁文字集的、所以會如下圖所顯示的狀態：

在拜過 Google 大神後發現都是需要修改設定檔的、然而在路徑中 /usr/local/mysql/support-files 裡卻找不到 my-default.cnf 或 my.cnf 文件。

原來是新版的 MySQL 在安裝時不會再自帶這2個設定檔了；所以只好自行新增囉。

$ cd /etc
$ sudo vim my.cnf

進入編輯界面後、將以下的設定資料拷貝進去：
