NTP Server on Synology

Posted by 曉羽 on Monday, March 26, 2018

續上篇、在更新完無線基地台後；基地台時間是無法校正的，主要是因為發配的 IP 是僅供管理而無權限可以上網的。為了讓基地台的時間可以校正，想到還有 Synology NAS 可以利用，只是查了一下官網說明，可能因為版本的不同而有些許差異；所以再記錄一下囉。

  • DSM 版本： DSM 6.1.5-15254 Update 1

  • DSM 日期： 2018/02/06

  • 控制台 -> 資訊中心 -> 系統服務 -> NTP 服務 -> 打勾 -> 儲存。

  • 無線基地台設定頁面 -> Setup -> Time Settings -> 選擇時區並輸入 NAS 的區網 IP 、完工。
