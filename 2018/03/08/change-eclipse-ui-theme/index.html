Change Eclipse UI Theme

Posted by 曉羽 on Thursday, March 8, 2018
更改 UI Theme 為黑底
  • Help -> Eclipse MarketPlace

  • Search “Eclipse Moonrise UI Theme” -> Click “GO” -> Install “Eclipse Moonrise UI Theme 0.8.9”

  • Search “Eclipse Color Theme” -> Click “GO” -> Install “Eclipse Color Theme 1.0.0”

  • 變更偏好設定：Eclipse -> 偏好設定

  • General -> Apperance -> Theme: Select “MoonRise(Standalone)” -> Click “Apply”

  • General -> Apperance -> Color Theme -> Subline Text 2 -> Click “OK”

  • Done!!!
