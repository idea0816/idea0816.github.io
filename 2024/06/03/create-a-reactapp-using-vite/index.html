使用 Vite 建立 React

Posted by 曉羽 on Monday, June 3, 2024

嘗試改用 Vite 建立一個新的 React。

npm create vite@latest
  1. 輸入專案名稱
  2. 輸入 Package 名稱
  3. 選擇開發工具（我選擇 React ）
  4. 選擇使用語言（我選擇 JavaScript ）

接下來依照提示：

  1. 進入專案資料夾
  2. npm install （安裝必要相依檔案）
  3. npm run dev
