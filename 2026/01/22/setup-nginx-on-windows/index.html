Install and configure Nginx on Windows

Posted by 曉羽 on Thursday, January 22, 2026

突然有需求在 Windows 系統上發佈 React 的程式、所以研究了一下作法如下：

安裝步驟：

下載 Nginx

先至官方頁面進行下載：官方網頁。 我選擇 nginx 1.29.4

下載好的 Nginx 包，可以放到自己便於管理的目錄進行解壓，例如 D 盤，解壓後即可使用。

啟動 Nginx

Windows+R 輸入 cmd。

進入 Nginx 目錄，輸入 start nginx 啟動 Nginx 。如下圖：

Nginx 相關指令

關閉、重啟 Nginx 。如下：

start nginx       #啟動 nginx
nginx -s reload   #重啟 nginx
nginx -s stop     #快速停止 nginx
nginx -s quit     #完整有序地停止 nginx

測試是否成功

啟動 Nginx 後，在瀏覽器的地址欄輸入http://ip:nginx埠號，例如：http://127.0.0.1:80，頁面出現 Nginx 即為安裝成功。如下圖：

React 發佈

先在 React 專案下執行：npm run build

會生成一個 dist 資料夾

將 dist 資料夾內的檔案全部 Copy 到 nginx\html 之下。(舊檔案全部取代)

啟動 nginx 。start nginx

完成。
